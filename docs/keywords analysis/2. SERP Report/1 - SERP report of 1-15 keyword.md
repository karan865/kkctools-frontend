## 2.7 Suggested tool scope

A useful roof replacement cost calculator could include:

- Roof area input, with square feet and other clear unit options.
- Roof shape / complexity selection, if the calculation method supports it.
- Roofing material selection (for example, asphalt shingles, metal, tile) with editable or clearly sourced cost assumptions.
- Tear-off / removal option.
- Underlayment and related material options, where supported by the estimate model.
- Labor and installation cost assumptions.
- Optional location adjustment, only if reliable regional cost data is available.
- Low / typical / high estimate range rather than false precision.
- Clear breakdown of materials, labor, removal, and optional extras.
- Explanation of assumptions, exclusions, and the date/source of any cost data.

Do not invent current roofing prices. If prices are added, identify the data source, geographic coverage, and last-updated date.

## 8.7 Recommended calculator scope

## 4. Competitor-by-competitor detail

### Omni — cap-rate (giant)

- Inputs: property value, annual gross income, opex (% or $), vacancy → NOI, cap rate. Long article: definition, formula, how to calculate, selling a property, evaluating value, NOI and cap-rate changes, **interest rates**, housing booms, good cap rate, evaluation techniques/ratios (CoC, ROI, DSCR, GRM), limitations.
- **FAQs (4):** good cap rate for rental · does cap rate include mortgage · do cap rates rise with interest rates · what does a 7.5 cap rate mean.
- **Errors:** says a 10% cap rate means cash flow “equals zero after ten years”; FAQ defines cap rate on **gross** income; example mixes % and $ opex; “good” ranges conflict (4–12% vs 8–12%).

### PropertyMetrics — cap-rate (CRE SaaS) — NOI build-up model

- Inputs: value, rentable SF, average rent/SF, vacancy & credit loss %, other income, taxes, insurance, maintenance, management %, reserves, other expenses → GPI, EGI, expenses, NOI, cap rate. Shareable URL.
- Walkthrough: 50,000 SF office at $35 → GPI $1.75M → EGI $1.625M → NOI $1.19M → value $15M → 7.93%. Excel section: ratio method, **band of investment**, **Gordon model** (cap = discount − growth).
- **Weak points:** walkthrough lists utilities/janitorial but calculator lacks fields; Excel gated; no FAQ, no author/date.

### Tyler Cauble — CRE cap rates (broker) — modes + presets

- **3 modes** (cap rate, value, NOI); **11 asset-class presets**; outputs incl. monthly NOI and price-to-NOI multiple.
- Content: formula; how to calculate (20,000 SF flex example); good cap rate in 2026; is 5/6/7/8% good; cap vs CoC/IRR/NOI; common mistakes; **pro forma vs T-12** (8.0% vs 5.5%).
- **FAQs (7):** what is a cap rate in CRE · good cap rate 2026 · is 5% / 7% / 10% good · how to calculate · what does 7.5% mean.
- **Errors:** ranges unsourced; inconsistent office figures; published 2023 presented as 2026; broken newsletter block; heavy course CTAs.

### Janover — hud.loans cap-rate (lender)

- NOI + market value → cap rate. Example $500,000 / $10M = 5%. Says no HUD-specific ranges. No FAQ, no author.

### REsimpli — cap-rate blog (investor CRM)

- **No calculator** despite the title. Steps, NOI factors, examples ($30,000 NOI at $400k = 7.5% vs $700k = 4.3%), **6 common mistakes** (opex, vacancy, valuation, confusing with CoC, no comps, over-reliance). Author, Jun 2026.

### Select Commercial — cap-rate (lender)

- NOI + price → cap rate (output placeholder); promises target-cap valuation but no input. 3 FAQs (what is a cap rate · good cap rate · NOI defined). $1.5M minimum loan messaging.

### Calculator.net — rental-property (giant, related)

- Full rental model (purchase, loan, closing, repairs, ARV, taxes, insurance, HOA, maintenance, rent, vacancy, management, appreciation, holding period, selling cost). Content: 50% / 1% / 70% rules, IRR, cap rate, CFROI. No examples, no FAQ. (Relevant for our Rental Property tool #7.)

## 5. Patterns

- **Maths:** NOI = (gross potential rent + other income − vacancy & credit loss) − operating expenses (excl. debt service, capex, depreciation, income tax) · cap rate = NOI ÷ value · value = NOI ÷ cap rate · NOI = value × cap rate · price-to-NOI = 1 ÷ cap rate.
- **Common errors in the SERP:** using gross instead of NOI; including mortgage; payback myth; mixing % and $ opex; stale “current” ranges.

## 4. Competitor-by-competitor detail

### Omni — percentage-increase (giant)

- Inputs initial/final + **increase/decrease toggle**; outputs % and difference. Formula 100 × (final − initial)/|initial|; examples $1,250 → $1,445 (15.6%), $1,445 → $1,300 (≈10%).
- **FAQs (10):** where useful · increase over time · add a % increase to a number · add 5% · add two percentages · 10% increase · make a percentage · what is a 50% increase · **percentage increase in Excel** · add 20%.
- **Error:** Excel steps multiply by 100 **and** apply Percent format → result shows 100× too large. “Add two percentages” answer is misleading.
- **Lesson:** FAQ topics (add X% to a number, Excel) are exactly the long tail in our keyword file. Answer them correctly.

### Omni — percentage-change (giant)

- Initial/final → percent change + step-by-step. Covers **negative numbers** (50 → −22 = −144%; −10 → −25 = −150%) and population growth.
- **FAQs (5):** is % difference = % change · change 5→20 · 20→10 · 2→3 · 5→4.
- **Lesson:** “change from A to B” example questions are popular FAQ phrasing.

### Calculator.net — percent-calculator (giant)

- One page, several mini-tools: basic P × V1 = V2; **3 common phrases** (what is X% of Y, X is what % of Y, X is Y% of what); percentage difference; percentage change (increase/decrease a value by %).
- **Weak points:** no FAQ; no (new − old)/old formula written out; formula images without alt text; no author/date.
- **Lesson:** the **all-in-one page** model — matches our keyword file's plan.

### CalculatorSoup — percentage-increase (giant)

- Start/final values (accepts hh:mm:ss time values); formula with |start|; one example (jeans $36 → $45 = 25%); video; related links (decrease, difference, change, error, tolerance). Author Edward Furey, updated Oct 2026. No FAQ; zero start not handled.

### Inch Calculator — percent-increase (giant)

- Two modes: percent increase (initial → final) and **increase a value by %**. Step-by-step. **FAQs (3):** is increase same as change · % increase when doubled · can it be negative. Author + PhD reviewer; no date.

### GIGAcalculator — percent-increase (large)

- Modes: increase by % → new value; x to y → %. Formula new/old × 100 − 100. **Real-life examples:** salary, hourly rate, customers, price with VAT, property value. Updated Oct 2026. No FAQ.

### MiniWebtool — percentage-increase (mid)

- Original/new → % with **step-by-step, bar chart, gauge, verification**; quick example buttons; zero start flagged undefined; results > 100% explained. Long content (formula, how to, understanding results, uses by field, scenarios, FAQ, tips, related, resources).
- **FAQs (6):** what is it · how to calculate · increase vs decrease · can it be > 100% · zero original · real life.
- **Weak points:** single mode; heavy repetition; date inconsistencies; ad-blocker modal.
- **Lesson:** visual output + edge-case explanations are liked; keep it lean.

### Rows — percentage-increase (SaaS)

- Two inputs, one output, ~150 words, product promotion. **No spreadsheet formula shown** despite being a spreadsheet company. Shows how thin pages can still rank for this term.

## 5. Patterns

- **Formulas (standard maths):** % change = (new − old) ÷ |old| × 100 · % difference = |a − b| ÷ ((a + b)/2) × 100 · increase by p% = x × (1 + p/100) · reverse original = new ÷ (1 + p/100) · X% of Y = X/100 × Y · X is what % of Y = X ÷ Y × 100.
- **Excel equivalents:** `=(B2-A2)/A2` (format as %), `=ABS(A2-B2)/AVERAGE(A2,B2)`, `=A2*(1+B2)`.
- **Gaps everywhere:** percent vs percentage points; reverse percentage; batch list; Excel done right.

## 7. Gaps nobody fills — our opportunities

1. **All percentage jobs on one page:** change (signed), difference (unsigned), increase/decrease by %, reverse (original), X% of Y, X is what % of Y — with tabs. Giants split these over 5+ URLs.
2. **Correct Excel/Google Sheets formula** generated for the user's inputs (copy button) — only Omni tries, and it's wrong.
3. **Percent vs percentage points** explainer (0 competitors) — e.g. interest rate 4% → 5% = +1 point = +25%.
4. **List mode:** paste many old/new pairs (price list) → change for each + average.
5. **Edge cases handled in the tool:** zero start (undefined → show absolute change), negative values, > 100% changes.
6. **Step-by-step with user's numbers** + a tiny visual bar (MiniWeb-style, lighter).
7. **Links to Markup, Margin, Discount** (all built on % maths) — internal link hub.
8. **Trust:** last-updated date, method note; author only if owner provides real details.

## 8. Blueprint for the KKCTools Percentage Change Calculator

### 8.1 SEO

- **URL:** `/percentage-change-calculator/`

- **H1:** Percentage Increase Calculator: Change, Decrease & Difference
- **Meta:** Free percentage increase calculator. Find the percent change between two numbers, the percent decrease or the percent difference, with the formula shown.

### 8.2 Calculator spec

| Area | Spec |
|---|---|
| Tabs | % change (old → new) · % difference · increase/decrease by % · find original · X% of Y · X is what % of Y |
| Outputs | %, absolute change, direction word (increase/decrease), step-by-step, Excel & Sheets formula |
| List mode | paste pairs → table of changes + average change |
| Edge cases | zero start → “undefined, absolute change = …”; negatives explained |
| UX | swap button, copy result, share URL, keyboard friendly, no network |

8. Percentage change in Excel and Google Sheets (formulas, formatting pitfall)
9. Percent vs percentage points
10. FAQ (10–12)

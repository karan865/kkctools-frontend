## 4. Competitor-by-competitor detail

### #1 — getjobber.com (AS 54)

- **Title / H1:** Lawn Care Cost Calculator
- **Calculator:** enter address → trace lawn on satellite map (sq ft) → draw edging lines (linear ft) → pick schedule (weekly / bi-weekly / monthly / one-time) → **user types own $/sq ft per service and $/linear ft edging**. Homeowner or pro toggle. **Name + contact required before results.**
- **Content:** “how to use”, why measure before a site visit; one formula (rate ÷ average sq ft); no prices, no tables, no examples.
- **FAQs (9):** what it does · accuracy · replaces site visits? · how measured · what to do with result · who it's for · online vs walk-and-measure · how to quote customers · how to invoice.
- **Weak points:** gated results; no default rates, so homeowners get nothing useful; an empty H3; app's 4.8 review schema pasted on the tool page.
- **Lesson:** the **map measuring** is the only real advantage — but it needs an API (not allowed for us). We beat it with a no-sign-up tool and real default rates.

### #2 — crewnest.app (AS 9) — the page to beat

- **Title:** Lawn Mowing Cost Calculator: $50-$80 for 5,000 Sq Ft (Free) · **H1:** Lawn Mowing Price Calculator
- **Calculator:** lawn size (default 5,000 sq ft) · lawn type (standard / overgrown +30% / fine −10%) · frequency (one-time / weekly −15% / bi-weekly −10% / monthly −5%) · terrain (flat / moderate +15% / steep +35%) · obstacles (none / moderate +15% / heavy +30%) · homeowner/crew toggle.
- **Outputs:** per visit, monthly, annual, est. time, effective rate per 1k sq ft, hourly rate, $/sq ft, low–you–high market range.
- **Content:** “quick answer” $/sq ft; pricing method; price by lawn size; price per acre; acres per hour by mower size; minimum job price; regional prices (5 regions); how to start a mowing business; contractor section.
- **FAQs (10):** average cost per acre · ½ acre · 10 acres · acres per hour · how much to charge · cost per sq ft · how often to mow · time to mow 1 acre · charge more for overgrown? · price for new customer.
- **Errors found (checked with arithmetic):**
  - Weekly 5,000 sq ft annual = $1,800–$2,800, but $50–$80 × 52 visits = $2,600–$4,160.
  - Bi-weekly annual uses 24 visits, not 26.
  - “Market range” mixes per-visit (low) with monthly (high $135).
  - Push mower 0.2–0.3 acres/hr in text vs ~2 hrs/acre in FAQ.
  - Overgrown surcharge “25–50%” in text vs +30% in calculator.
- **Trust:** no author, no date, no sources.
- **Lesson:** strongest **feature + content model** in the SERP at AS 9. Match its inputs and outputs, then beat it with **correct maths**, a season length input, sources and a date.

## 7. Gaps nobody fills — our opportunities

1. **Transparent, ungated maths.** 0 of 9 show every rate and let the user change it with no sign-up. → All rates visible and editable; formula shown under the result.
2. **Correct season maths.** Crewnest and WhatGrass both have annual/per-visit errors. → Season length (weeks) + frequency → exact visit count; annual = visits × price; unit-tested.
3. **Both views in one tool.** → Toggle **“What will I pay?”** (homeowner, market defaults) vs **“What should I charge?”** (pro: hourly target, mower width → time on site, travel, overhead, margin, minimum charge).
4. **Time-based pro pricing.** Only WhatGrass explains it, nobody calculates it from mower size. → Mower deck width + speed → acres per hour → minutes on site → price at chosen hourly rate.
5. **Bi-weekly priced right.** Bi-weekly grass is longer, so per-visit is usually higher; most tools only discount. → Make the frequency multiplier editable in both directions and explain why.
6. **Metric + acres + sq ft together.** Only Connecteam has m². AU is 260/month. → sq ft / acres / m² with converting switch; currency selector (USD, AUD, GBP, CAD).
7. **Lawn size helper without APIs.** Map tools need network calls (not allowed). → Preset sizes (¼ acre lot, etc.) + simple rectangle/multi-area adder (front, back, sides).
8. **Per-acre and price-by-size table generated by our engine.** → Table rows come from the calculator, so they never contradict it.
9. **Trust:** no page has a named author; few have dates and sources. → Last-updated date, sources list, methodology. *Author only if owner provides real details.*
10. **Copy / print / share** with no email gate (URL state only).

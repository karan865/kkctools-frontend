## 4. Competitor-by-competitor detail

### #1 — inchcalculator.com/board-and-batten-layout-calculator/ (AS 81)

- **Title / H1:** Board and Batten Layout Calculator
- **Calculator:** 2 modes — *space between battens* (wall width, batten width, approx. spacing) or *number of battens* (wall width, batten width, count). Outputs: battens required, exact space, layout drawing, **batten locations**. Share + embed.
- **Content:** 3 steps (measure, preferred spacing, exact spacing) with a 5-part formula: (batten + space) → remaining width = wall − batten → spaces = remaining ÷ (batten + space), rounded → exact unit → exact space. Diagram naming battens, baseboard, top board, chair rail.
- **FAQs:** what wood · how thick · plywood underneath?
- **Weak points:** never says battens = spaces + 1 in plain words; static drawing; no rails, no doors/windows/outlets, no materials list; no sources or date. Claim “most common spacing 10–12 in” unsourced.
- **Lesson:** this is the **feature bar** — two modes + batten locations. Beat it with fractions, rails, a live drawing, a materials list and clear battens/gaps wording.

### #2 — mrsashleyfrench.com (AS 22)

- Blog post walking through InchCalc's **wainscoting** calculator (wall width, stile width, number of panels → panel width) with 8 / 7 / 6 panel trials until it “looks right”.
- Useful tips: measure the real batten width with a tape (a 1×3 is ~2.5"); cut a **spacer block** to the gap for fast install; working with or without existing baseboards.
- **Errors:** spacer size written as “16 3/6"” (not a real fraction); never states the calculated gap.
- **Lesson:** users try several counts to see which looks best → our tool should **show 3–4 options side by side** (e.g. 6, 7, 8 battens with resulting gaps).

### #3 — calconic.com (AS 35) — widget demo, not analysed

A no-code widget builder showcase. A thin widget ranking #3 = weak SERP.

### #4 — wallpanelplanner.com/tools/batten-spacing-calculator (AS 11) — best small competitor

- **Title:** Board and Batten Calculator | Free Batten Spacing Tool
- **Calculator:** mm/inches; wall width, wall height, batten width, batten count (stepper); **fractions accepted**; **1×2–1×8 buttons fill actual width**. Output: even gap, live preview, open in planner.
- **Content:** how to space evenly; common wall widths (mm table 1,800–3,600 and inch table 120–192 in, all checked correct); nominal vs actual lumber table; plan whole wall; grid vs plain battens; battens vs slats vs panels.
- **FAQs (7):** how to space evenly · how many battens · batten width · formula · how far apart · board sizes · do end battens sit at the wall edge?
- **Weak points:** wall height entered but unused; battens fixed at both edges (edge gap is paid); no author/date/sources; funnels to a paid planner.
- **Lesson:** correct, clean and metric-first — **matches our Europe/UK goal**. We must at least match: fractions, lumber presets, live preview, and ship the paid features (rails, grid, cut list) free.

### #5 — YouTube Short · #9 texas.gov · #10 rewiringamerica.org

Junk/irrelevant slots — open for a strong tool page.

### #6 — homebyalley.com (AS 17)

- **Title:** The BEST Board and Batten Wall Spacing Calculator (EASY and FAST)
- Embedded calculator (assumes 8 ft boards), output = edge-to-edge gap. Formula: (wall width − total board width) ÷ number of spaces. ~300 words, comments, affiliate disclosure.
- **Weak points:** “number of spaces” undefined (n−1 vs n+1); hover-only tips (bad on mobile).
- **Lesson:** a 300-word page ranks #6 — the tool itself is the content.

### #7 — itshoneydone.com (AS 15)

- Blog post (Feb 2023) that again sends readers to InchCalc's wainscoting tool. Steps before using it, build your accent wall.
- **Weak points:** stile vs batten vs panel terms confused; no units; no example.
- **Lesson:** **terminology confusion is real** (stile, batten, panel, gap). A short glossary + labelled diagram will help.

### #8 — omnicalculator.com/construction/board-and-batten (AS 84) — exterior siding

- **Calculator:** wall width/height; board width and spacing; doors and windows (count + size); trims (default 2); board/batten/furring/trim materials. Outputs: number of boards, battens, furring rows, trims; linear material for each.
- **Content:** what board and batten siding is; formula (battens = boards ± 1 depending on edges); 2 metric examples; material types.
- **FAQs (4):** what is it · how much material · same as wainscoting? · how many battens.
- **Errors:** furring example 9 rows × 3 m = 27 m, page says 30 m; examples use boards − 1 while the stated default is boards + 1.
- **Lesson:** the **siding mode** (boards + battens + furring + openings) is a second audience we can serve with one extra mode.

## 5. Patterns

- **Core formula (accent wall, battens at both edges):** gap = (wall width − battens × batten width) ÷ (battens − 1). From a target gap: battens = round((wall width − batten width) ÷ (batten width + target gap)) + 1.
- **Spacing advice quoted (unsourced everywhere):** 10–12 in (InchCalc), 16–24 in (Wall Panel Planner). Treat as style choice, show the options.
- **Nominal vs actual widths** (standard US softwood sizes — verify from a lumber standard): 1×2 = 1½", 1×3 = 2½", 1×4 = 3½", 1×6 = 5½", 1×8 = 7¼".
- **Nobody gives a shopping list for an accent wall** (how many 8 ft boards, nails, adhesive, caulk, paint).
- **0 of 6** pages cite a source; 1 shows a date.

## 7. Gaps nobody fills — our opportunities

1. **Compare options side by side.** Users try 6 / 7 / 8 battens until it looks right. → Show a small table of nearby counts with resulting gaps and a mini preview each.
2. **Accent wall shopping list.** → Number of 8 ft (or 2.4 m) boards with cut list, linear feet, top rail + baseboard length, nails, construction adhesive, caulk, paint/primer area.
3. **Rails and grid patterns free.** → Top rail, middle rail(s), baseboard; grid/square layout (paid on Wall Panel Planner).
4. **Edge options.** → Battens at both edges / inset from edges / boards on one edge only.
5. **Fractions + rounding to 1/16".** → Inches with fractions; results shown as nearest 1/16" and as decimal; mm for metric.
6. **Batten mark positions.** → List of distances from the left wall (only InchCalc does this).
7. **Openings.** → Mark doors, windows, outlets on the layout so users see clashes (nobody does).
8. **Exterior siding mode.** → Boards + battens + furring + openings deducted, with linear feet (Omni only, and its example has an error).
9. **Clear terms.** → Glossary: batten, board, stile, rail, gap, on-centre — with labelled SVG diagram.
10. **Trust.** → Last-updated date, methodology, sourced lumber sizes.

## 4. Competitor-by-competitor detail

### #1 — homedepot.com cost-bathroom-remodel (AS 99)

- **H1:** Bathroom Remodeling Cost Guide — **no calculator**.
- Content: cost tiers (quick updates $3k–$8k, minor $15k–$25k, major $30k+); what matters (why, timeline, budget); materials & features (tub, vanity, counter, sink, toilet, tile); considerations (geography, permits, disposal, water damage, labour 40–65%, structural +30–100%).
- **FAQs (5):** realistic budget · tax deductible? · best time to renovate · what adds most value · hidden costs.
- **Weak points:** no tool; gap between $25k and $30k; no sources; heavy financing CTAs.
- **Lesson:** ranks #1 on brand. **Scope tiers** and **hidden costs** are the structure users expect.

### #2 — costflowai.com/calculators/bathroom/ (AS 21)

- Quick (5) / Professional (35 inputs). Bathroom type (half, full, master, luxury master, custom); scope (cosmetic, refresh, mid-range, full remodel, expansion); vanity plan (keep / stock / semi-custom / custom × single/double); shower plan (keep, prefab, tile surround, custom tile, curbless, steam, tub-to-shower); floor material; ZIP. Output: range (pro: itemised).
- **Weak points:** no prices on the page; core rates unsourced; half bath = 20% of full-bath base (loosely sourced); no FAQ.
- **Lesson:** **vanity plan + shower plan** as two separate choices is a clear way to model the biggest cost items.

### #3 — badeloft.com bathroom-remodel-cost-calculator (AS 34) — **the page to beat**

- **Title / H1:** Bathroom Remodel Cost Calculator: Instant Estimates With the Math Shown
- **Calculator:** size (5×7, 5×8, 5×10, 8×10, 10×11+, custom 18–250 sq ft); scope (refresh / pull and replace / full gut / full gut + layout change); finish (budget / mid / luxury); wet-area plan (replace tub, walk-in shower, freestanding tub, tub + separate shower); labour market (−15% / national / +20% / +35%); who does the work (pros / hybrid DIY). Outputs: range, most-likely figure, **9-line category breakdown**, contingency. Plus a **Quote Reality Check** (enter a bid → low / fair / overpriced zone).
- **Content:** how it builds the estimate; costs by size and scope matrix; where the money goes; what pushes it up; tub vs shower decision; pressure-test a quote.
- **FAQs (5):** is $5,000 enough · $10,000 · $20,000 · what's a good budget · how accurate are online calculators.
- **Errors:** contingency 10–15% vs 10–20%; demolition $800–$2,000 vs $500–$2,300; refresh range in FAQ ≠ table; multipliers not disclosed despite “math shown”.
- **Lesson:** best model in the SERP. **Budget-question FAQs ($5k / $10k / $20k)** and the **quote checker** are smart. We beat it with editable line items, no brand bias, half-bath mode, currency.

### #4 — houzz.com cost-to-remodel-a-bathroom (AS 74)

- Options calculator: size (small <30 / medium 30–100 / large >100 sq ft), type (primary/guest), shower type (5), bathtub type (6), flooring (6), shower wall material (7), vanity (single/double), countertop (8). Output: estimated cost (not visible). National average $12,350–$13,650.
- **Errors:** copy-paste from a roofing page (“cost to replace your roof”, asphalt shingles example); unsourced ROI ~70%.
- **Lesson:** a **material picker** per surface is what homeowners like to play with.

### #5 — joycefactorydirect.com/joyce-bath-calculator (AS 25)

- Bath/shower installer: project type (tub replacement, shower replacement, tub-to-shower, walk-in tub, bath refresh), wall style, fixtures, doors, storage, upgrades. Output range not shown; financing $135–$165/month.
- **FAQs (8):** accuracy · info needed · includes installation? · why no exact online price · options · what raises cost · tub-to-shower · full remodels?
- **Lesson:** **tub-to-shower conversion** and **walk-in tub** are distinct searched projects (accessibility).

### #6 — surprisegranite.com → remodely.ai (AS 15)

- Redirected. Remodely tool: shower wall sq ft, floor sq ft, vanity width (in), vanity top (quartz, granite, marble, laminate, none), tile level, add-ons. Output not captured.
- **Lesson:** **area-based tile (shower walls + floor)** and **vanity width** give real quantities; nobody else does this.

### #7 — modernize.com shower cost-calculator (AS 47)

- **Shower remodel** calculator (style, size, base, fixtures, ZIP → ballpark). Content: cost by shower type, size, fixtures, plumbing, labour, tile per sq ft, hidden costs, save money, FAQ (home value, permit, timeline, cheapest update). Writer + reviewer, Aug 2026; no sources.
- **Lesson:** Google mixes **shower remodel** intent into this SERP → include shower-only mode.

### #8 — sofabrain.com bathroom-remodel-cost-calculator (AS 22)

- Size (15–200 sq ft), quality (budget $80–$140 / mid $200–$350 / upscale $450–$800 per sq ft), add-ons (move plumbing, tub-to-shower, heated floor, permits). Output range, midpoint, $/sq ft. Report gated by email.

- **Lesson:** **per-sq-ft alone fails small bathrooms** (fixtures cost the same) — our model must combine fixed fixture costs + area-based costs.

## 5. Patterns

**Cost model types seen:**
1. **Tier ranges** (Home Depot) — no calculation.
2. **Per sq ft × quality** (SofaBrain) — wrong for small rooms.
3. **Scope × size × finish multipliers** (Badeloft, CostFlowAI) — hidden multipliers.
4. **Material/fixture pickers** (Houzz, Joyce, Remodely) — hidden prices.

**Best approach for us:** fixed items (toilet, vanity, tub/shower, faucet, fan, lighting, permit) + area items (floor tile, wall tile, paint, drywall) + labour (per trade or % ) + scope multipliers (demo, plumbing moves) + region + contingency — **every price visible and editable**.

## 7. Gaps nobody fills — our opportunities

1. **Every line item visible and editable** — 0 of 8 competitors allow editing unit prices.
2. **Fixed + area-based model** so small bathrooms aren't under-priced (SofaBrain's flaw).
3. **Bathroom type modes:** half bath / powder room, full, primary, shower-only, tub-to-shower.
4. **Quantities:** floor tile sq ft, wall tile sq ft, grout/thinset, paint — link to our Tile and Paint calculators.
5. **DIY vs pro per trade** (demo DIY, tile pro, plumbing pro…).
6. **Quote checker** (Badeloft has it) — done neutrally.
7. **Currency + metric** (USD / GBP / EUR / AUD; m²) — 0 competitors. Keyword file asks for USD/GBP/EUR.
8. **Contingency, permits and hidden-cost line** with clear defaults.
9. **Budget-scenario FAQs** answered from our engine ($5k / $10k / $20k builds).
10. **Neutral + sourced** — no brand push, no email gate; dated price basis.

## 5. Patterns

**Cost components across the SERP:** decking boards (by material) · substructure (joists, beams, posts, footings, ledger, hardware) · fasteners (screws or hidden clips) · railing (by type, lf) · stairs (risers × width) · labour (by material and height) · permit · demolition/haul-away (replacement) · site prep · region.

**Material maths:** boards = (deck width ÷ (board width + gap)) rows × deck length ÷ board length (+ waste by angle); joists = deck length ÷ spacing + 1; footings by beam/post spacing; railing lf = perimeter − house side − stair openings.

## 7. Gaps nobody fills — our opportunities

1. **Neutral, brand-free estimator** with every price editable (0 of 4).
2. **Materials list + cost together:** boards by length, joists, beams, posts, footings (link Concrete Calculator for footing concrete), fasteners, railing parts, stair stringers/treads.
3. **Side-by-side materials:** PT pine, cedar, composite, PVC, hardwood — upfront and lifetime cost (link Deck Stain for wood maintenance).
4. **Replacement & repair modes:** resurface (new boards on existing frame), full replace (demo + new), board replacement count — 5 secondary keywords target these and **no competitor models them**.
5. **Several deck sections / L-shapes / multi-level.**
6. **Height and access** as clear multipliers (shown, editable).
7. **DIY vs pro** with labour per sq ft (sourced, e.g., BLS-based).
8. **Metric + currency** (UK/AU “decking”) — 0 competitors.
9. **Engine-generated deck-size table** (10×10 … 20×20) — Trex/CostFlowAI tables contradict themselves.
10. **Trust:** date, sources, methodology; no AI-generated filler.

## 8. Blueprint for the KKCTools Deck Cost Calculator

### 8.1 SEO

- **URL:** `/deck-cost-calculator/`
- **Title (55 chars):** Deck Cost Calculator – Wood, Composite & Trex Estimator
- **H1:** Deck Cost Calculator & Estimator
- **Meta:** Free deck estimator: enter deck size and material (pressure-treated, cedar, composite or Trex) to estimate materials, labour and total deck cost.
- Note: “Trex” is a brand used in search terms; use it only in descriptive text (“Trex-style composite”), no logos or impersonation.

### 8.2 Calculator spec

| Area | Spec |
|---|---|
| Mode | New deck · Resurface (new boards/railing on existing frame) · Replace (demo + new) · Repair (replace N boards) |
| Size | sections (L × W), height above grade, attached/freestanding; ft or m |
| Decking | material preset (PT, cedar, redwood, composite, PVC, hardwood), board width & length, gap, angle/pattern, picture-frame |
| Framing | joist size/spacing, beams, posts, footings (concrete per footing via Concrete engine) |
| Railing | type (wood, composite, aluminium, cable, glass), length (auto from perimeter − house side − stairs) |
| Stairs | count of risers, width, landing |
| Fasteners | screws or hidden clips per board crossing |
| Costs | each material editable; labour per sq ft (material × height); permit; demo & disposal; region multiplier |
| Outputs | bill of materials, line items, total, low / typical / high, $/sq ft, DIY vs pro, material comparison |
| Locale | currency |
| UX | print BOM, copy, share URL, no network |

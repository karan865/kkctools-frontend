## How to read the SERP columns

The 1-36 file shows **Domain AS** (whole-site authority), not page-level links. Each top-10 result is grouped as:

- **Giant** = AS ≥ 60 calculator/guide site (Omni, Calculator.net, Inch Calculator, Home Depot…) — hard for DA 1.
- **Mid** = AS 21–59. Beatable with a better tool + some links.
- **Weak** = AS ≤ 20. Directly beatable.
- **Junk** = YouTube, app store, Facebook, Reddit, Quora/Brainly, or an irrelevant page (irs.gov, texas.gov…). A good tool can take these slots.
- **Open slots = Weak + Junk.** More open slots and fewer giants = easier for a DA 1 site.
- Keyword flags: ⚠ irregular trend = volume unreliable · ⚠ declining · 🌍 UK/EU/global term · FAQ/H2 = content use only. Source column: CSV = Semrush export, SERP = SERP screenshot (no CPC).

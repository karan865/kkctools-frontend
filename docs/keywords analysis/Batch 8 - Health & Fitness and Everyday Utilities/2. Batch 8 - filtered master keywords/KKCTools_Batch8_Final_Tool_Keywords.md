## How keywords were selected (DA 1 filter)

1. **Primary KD ≤ 15**, or a long-tail cluster where most rows are KD ≤ 20 and one engine-built table answers all of them.
2. **Health is YMYL.** Clinical tools (dosage, QTc, burns, infant feeding) are out. Everyday fitness calculators are allowed only with a named formula, a cited source, an “estimate, not medical advice” line and a qualified reviewer (`TODO(owner)`).
3. **The tool must work 100% in the browser.** Time zones use the browser’s own Intl data; clocks use the device clock (no time server).
4. **No thin pages:** “90 days from today”, “3/8 as a decimal”, “1700 military time”, “30 minute timer” are each answered by **one** page with a generated table or presets, never one URL per number.
5. **No brand, app or “what time is it in X” intent** — Google answers the current time itself.

**Rank chance:** ✅ good = exact tool term or long tail at KD ≤ 15 with no single dominant site · 🟡 possible = giants / Google’s own answer box / KD 16–29 in the way; needs links and a clearly better tool.

## What these exports tell us (read first)

- **The everyday utilities are the real win, not health.** The date, time, Roman numeral, fraction and kitchen seeds produced huge long tails at KD 0–15 with zero YMYL risk.
- **The seeds drifted.** `water intake calculator` pulled in cooking conversions (cups / tbsp / grams) and `roman numeral converter` pulled in fraction-to-decimal and unit conversions. These became their own tools.
- **Most seed heads are missing** (`muscle gain calculator`, `pomodoro timer`, `time zone converter`, `roman numeral converter`, `days between dates calculator`, `bmr calculator`, `tdee calculator`); they are KD > 30. Pull them (Section 6).
- **Health SERPs are crowded** even where Semrush KD is low (calculator.net, NIH, CDC, Mayo Clinic). Those tools are 🟡 / Tier 2. Narrow fitness tools (Army body fat, 1RM, heart-rate zones, ideal weight, water intake) are the health picks for Tier 1.
- **Google answers many of these itself** (timers, “X pm pst to est”, “what is 90 days from today”). Expect fewer clicks than the volumes; the page must offer more than the answer box (tables, presets, charts, full screen).
- **Semrush volumes for single big phrases look inflated** (`calorie calculator` 4,090,000, `proportion calculator` 1,220,000). Treat them as rough.

## How to read the tables

- **Role:** Primary = the page’s main target · Secondary – easy = KD ≤ 15 · Secondary – medium = KD 16–24 · Support = KD 25–30, use in H2 / FAQ.
- **Intent** (Semrush codes, decoded as 0 = Info, 1 = Nav, 2 = Comm, 3 = Trans).
- **Trend:** ⚠ irregular = 4+ months at zero · ⚠ declining = last 3 months under half of the first 3 · ↑ rising = last 3 months over 1.6× the first 3.
- **Long-tail rows** (“… queries (N phrases)”) sum many near-identical searches answered by one table / preset block on the page. KD is shown as the range.

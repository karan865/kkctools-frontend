## 2. Our edge

- **Both directions,** 1–3,999 standard; optional **vinculum** (overline, ×1,000) up to 3,999,999, shown with a real combining overline (U+0305).
- **Validation that explains:** non-standard input is converted *and* corrected with the rule it breaks (IIII → IV "no more than three of the same symbol in a row"; IC → XCIX "I can only come before V or X"; VX → V "V, L and D are never subtracted"; the full list and messages are in §3.4). IIII is accepted with a clock-face note.
- **Date mode:** MM.DD.YYYY, DD.MM.YYYY, YYYY.MM.DD; separators `.` `•` `-` `/` space `_` none; **real-date check** (no Feb 30; leap years).
- **Outputs to copy:** UPPER, lower, and **Unicode numerals** (Ⅳ, Ⅻ single characters for 1–12; Ⅿ Ⅾ Ⅽ Ⅼ Ⅹ Ⅴ Ⅰ letters above 12).
- **Step-by-step breakdown:** 1994 = M (1000) + CM (900) + XC (90) + IV (4).
- **Complete charts:** 1–10, 1–100 and years 1900–2100, all generated by the engine, printable.
- **Use-case guide** in our words: clocks, film credits, monarchs and popes, outlines, Super Bowls, tattoos.

### 3.4 Engine (`src/lib/roman-engine.ts`)

```ts
TOKENS = M 1000, CM 900, D 500, CD 400, C 100, XC 90, L 50, XL 40, X 10, IX 9, V 5, IV 4, I 1
toRoman(n): greedy over TOKENS ; vinculum: thousands part → toRoman(floor(n/1000)) with U+0305 after each letter, + toRoman(n % 1000)
parseRoman(s): normalise (trim, upper, strip spaces) ; value = Σ (a < next ? −a : +a) ; reject letters outside IVXLCDM
  canonical = toRoman(value) ; issues = rules broken when s !== canonical:
    - "IIII"/"XXXX"/"CCCC"/"MMMM": more than three in a row (clock note for IIII)
    - "VV"/"LL"/"DD": V, L and D are never repeated
    - "VX"/"LC"/"DM"…: V, L and D are never subtracted
    - "IC"/"IL"/"ID"/"IM", "XD"/"XM": I only before V/X, X only before L/C, C only before D/M
    - "IIX"/"XXC": only one smaller symbol may come before a larger one
    - order/other: "not in standard order"
unicode(n): 1–12 → U+2160+(n−1) ; else map letters I→Ⅰ V→Ⅴ X→Ⅹ L→Ⅼ C→Ⅽ D→Ⅾ M→Ⅿ (lower: U+2170 block)
romanDate(y, m, d, layout, sep): validate the real date (leap years) then convert each part
breakdown(n) → [{token, value}]
```

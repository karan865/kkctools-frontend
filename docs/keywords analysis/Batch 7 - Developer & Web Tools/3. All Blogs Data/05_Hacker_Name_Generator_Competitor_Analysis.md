## 5. Patterns

**Engine (reuse the Band Name Generator)**
- Template patterns per style:
  - **l33t:** a word with character substitutions (a→4, e→3, i→1, o→0, s→5, t→7), applied at a chosen density
  - **cyberpunk:** adjective + tech noun, or a neon-noir compound
  - **minimal:** one short word + digits
  - **gamer tag:** prefix/suffix + seed word, with an underscore or CamelCase option
  - **terminal:** words written like code, e.g. `null_vector`, `0xGhost`
- An **original word bank** (adjectives, tech nouns, verbs, prefixes, suffixes), written by us and reviewed for offensive terms.
- Seed word: optional, inserted or blended into the name.
- RNG: `crypto.getRandomValues` (shared with #1). The output doesn't need to be secure, but one RNG keeps the code simple.

**Options**
- Count: 5–30.
- Length range.
- Allowed characters (letters/digits/underscore only, spaces on or off).
- Case: lower, Camel or UPPER.
- **Platform rule hint:** an optional check of length and allowed characters for a chosen platform, using a data file with a `checkedOn` date. `TODO(owner)`: decide whether to include it; if yes, cite each platform's help page.

**Favourites and output**
- Favourites in localStorage (wrapped in try/catch), plus copy and copy-all.

**Safety**
- No real hacking instructions.
- A filter against slurs and profanity.
- Avoid names that copy real people or brands.

## B5. Mathematical Engine Specification

### 5.1 Generic Block Geometry
$$\text{unitLength} = \text{actualLength} + \text{jointInches}$$
$$\text{unitHeight} = \text{actualHeight} + \text{jointInches}$$
$$\text{blocksPerSqFt} = \frac{144}{\text{unitLength} \times \text{unitHeight}}$$

- For standard 8×8×16 ($15.625" \times 7.625"$):
  - With $3/8"$ joint: $16" \times 8" \implies 144 / 128 = 1.125\text{ blocks / sq ft}$.
  - With $1/2"$ joint: $16.125" \times 8.125" = 131.0156\text{ sq in} \implies 144 / 131.0156 = 1.0991\text{ blocks / sq ft}$.

### 5.2 Multi-Wall & Opening Net Area
$$\text{Gross Area} = \sum (\text{Length} \times \text{Height} \times \text{Quantity})$$
$$\text{Net Area} = \max(0, \text{Gross Area} - \text{Openings Area})$$
$$\text{Net Blocks} = \text{Net Area} \times \text{blocksPerSqFt}$$
$$\text{Total Blocks to Order} = \text{guardedCeil}(\text{Net Blocks} \times (1 + \text{Waste } \% / 100))$$
*where $\text{guardedCeil}(x) = \text{Math.ceil}(x - 10^{-9})$ to prevent floating-point rounding artifacts.*

### 5.3 Mortar Bag Yields
- Pre-blended mix (80 lb bag): Yields 13 blocks per bag. $\text{Bags} = \text{guardedCeil}(\text{Blocks to Order} / 13)$.
- Pre-blended mix (60 lb bag): Yields 9.75 blocks per bag. $\text{Bags} = \text{guardedCeil}(\text{Blocks to Order} / 9.75)$.
- Masonry cement (80 lb bag): Yields 35 blocks per bag. $\text{Bags} = \text{guardedCeil}(\text{Blocks to Order} / 35)$.

### 5.4 Core Fill (Grout) Calculations
- Hollow core volume per block (typical cu ft): 4" = 0.06, 6" = 0.17, 8" = 0.27, 10" = 0.38, 12" = 0.48.
- Share of cores grouted:
  - None: 0%
  - All (solid): 100%
  - 32" o.c. vertical rebar (1 cell in 4): 25%
  - 48" o.c. vertical rebar (1 cell in 6): 16.6667%
- Core fill volume is calculated strictly from **Net Blocks laid** (not waste-inflated order quantity):
$$\text{Base Grout Volume (cu ft)} = \text{Net Blocks} \times \text{coreVolume} \times \text{share} + (\text{Bond Beam Courses} \times \text{Blocks per Row} \times \text{coreVolume})$$
$$\text{Grout Volume with Waste (cu ft)} = \text{Base Grout Volume} \times (1 + \text{Grout Waste } \% / 100)$$
$$\text{Cubic Yards} = \text{Grout Volume} / 27$$

### 5.5 H2 — Understanding Your Results

- **Rafter length (along top edge):** The length of a common rafter measured along its top edge, from the plumb cut at the ridge to the plumb cut at the tail, including the overhang.
- **Board length to buy:** The next standard lumber length (even feet, up to 20 ft) that fits the rafter's longest point.
- **Run:** The horizontal distance a rafter covers. For a gable roof it is half the span.
- **Total rise:** The vertical height from the top of the wall plate to the ridge line.
- **Slope factor:** The number you multiply the run by to get the length along the slope. A 6/12 roof has a slope factor of 1.118.
- **Plumb cut angle:** The angle of the vertical cut at the ridge and tail, measured from a square (90°) cut.
- **Level (seat) cut angle:** The angle of the horizontal cut that rests on the wall plate, measured from a square cut.
- **Heel cut depth:** How deep the vertical side of the birdsmouth notch is. Keep it small so the rafter stays strong.

### 5.6 H2 — Rafter Length Calculator: Formula and Worked Example

A common rafter is the sloped board that runs from the top of the wall up to the ridge. Because the rafter, the run and the rise form a right triangle, you can find its length with the Pythagorean theorem. This rafter length calculator uses exactly that formula.

**H3 — Rafter length formula**

```
Run            = Span ÷ 2                       (gable roof)
Rise           = Run × (Pitch ÷ 12)
Slope factor   = √(1 + (Pitch ÷ 12)²)
Rafter length  = Run × Slope factor
Total length   = Rafter length + (Overhang × Slope factor)
```

Subtract half the ridge board thickness from the run first. A 1½ in ridge board means taking ¾ in off the run, so the rafter butts against the ridge board instead of reaching the centerline. For a shed roof, the run equals the full span and there is no ridge deduction.

**H3 — Worked example: 24 ft span, 6/12 pitch**

Building span 24 ft (288 in), pitch 6/12, overhang 12 in, ridge board 1½ in.

1. Run = 288 ÷ 2 = **144 in**
2. Adjusted run = 144 − 0.75 = **143.25 in**
3. Slope factor = √(1 + 0.5²) = **1.118**
4. Rafter length to the wall line = 143.25 × 1.118 = **160.16 in**
5. Overhang along the slope = 12 × 1.118 = **13.42 in**
6. Total rafter length = 160.16 + 13.42 = **173.57 in = 14 ft 5 9/16 in**
7. Total rise = 144 × 6 ÷ 12 = **72 in (6 ft)**

Rafter length is measured along the top edge. At a plumb-cut tail the bottom corner sticks out slightly farther, so the calculator checks the board's longest point (about 14 ft 9¼ in here) before it suggests a stock length. Result: buy **16 ft** boards.

**H3 — 4/12 Roof Pitch**

A 4/12 roof pitch rises 4 inches for every 12 inches of run. That is an angle of 18.43° (a 33.3% slope), so **4/12 pitch in degrees is about 18.4°**. Rafters on a 4/12 roof are 12.65 in long for every 12 in of run (slope factor 1.054). It is generally where the "conventional" pitch range begins.

**H3 — 6/12 Roof Slope**

A 6/12 roof slope rises 6 inches per 12 inches of run, which is 26.57° or a 50% slope. Each foot of run adds 13.42 in of rafter length (slope factor 1.118). It is a very common pitch on US houses and the one used in the worked example above.

### 5.8 H2 — How to Calculate Roof Pitch

Roof pitch is the rise divided by the run, multiplied by 12:

```
Pitch (per 12) = (Rise ÷ Run) × 12
```

**H3 — With a level and tape measure**
Hold a 12 in level horizontally against the underside of a rafter (from the attic). At the 12 in mark, measure straight up to the bottom of the rafter. That measurement is your pitch: 6 in means a 6/12 roof.

**H3 — From an angle**
Multiply the tangent of the angle by 12. For a 30° roof: 12 × tan(30°) = 6.93, so the pitch is about 7/12. To go the other way, angle = arctan(pitch ÷ 12).

**H3 — From span and ridge height**
Divide the ridge height above the wall plate by half the span, then multiply by 12. A 6 ft rise over a 12 ft run gives (6 ÷ 12) × 12 = 6, or 6/12. In this calculator, choose *Rise & run* and enter the total rise.

### 5.9 H2 — Rafter Span, Size & Spacing

Looking for a rafter span calculator? First, know that the **span** of a rafter is the horizontal distance it covers between supports — not the length of the board. A rafter that is 13.4 ft long on a 6/12 roof spans only 12 ft horizontally.

How far a rafter can safely span depends on the lumber species and grade, the board size, the spacing (commonly 12, 16 or 24 in on center), the roof load (snow, wind and dead load) and whether you use rafter ties or ceiling joists. These factors change by region, so **this calculator finds rafter length and cut angles — it does not size rafters**. Use the rafter span tables in your local building code (in the US, the International Residential Code), the American Wood Council's free span calculator, or ask a licensed engineer or your local building department.

**H3 — Rafter Dimensions (Nominal vs. Actual Size)**

Lumber is sold by nominal size, but the real dimensions are smaller. Use the actual depth when you check the birdsmouth.

| Nominal size | Actual size (in) |
|---|---|
| 2x6 | 1½ × 5½ |
| 2x8 | 1½ × 7¼ |
| 2x10 | 1½ × 9¼ |
| 2x12 | 1½ × 11¼ |

### 5.10 H2 — How to Mark and Cut a Rafter (Plumb Cut, Seat Cut & Birdsmouth)

- **Plumb cut:** the vertical cut at the ridge end (and at the tail if you cut it vertical).
- **Seat cut (level cut):** the horizontal cut that rests on top of the wall plate.
- **Heel cut:** the vertical cut that meets the seat cut and forms the birdsmouth notch.
- **Birdsmouth:** the notch made by the seat cut and heel cut. The seat length usually equals the width of the wall plate (3½ in on a 2x4 wall). The heel depth equals the seat length × pitch ÷ 12 — for a 6/12 roof on a 3½ in plate, that is 1¾ in.

**Marking with a speed square:** place the pivot point on the board edge and rotate the square until the board edge lines up with your pitch number on the *Common* scale (6 for a 6/12 roof). Scribe along the straight edge of the square to mark the plumb cut.

**Tip:** cut one rafter first, test-fit it on the wall and ridge, then use it as a pattern for the rest. As a common rule of thumb, keep the heel cut depth to no more than about one-third of the rafter's depth. Some codes are stricter, so check yours. The calculator flags deep birdsmouth cuts.

### 5.11 H2 — Common Rafter Mistakes to Avoid

- **Using the run as the rafter length.** The run is horizontal; the rafter is longer because it slopes.
- **Forgetting the ridge board deduction.** Take half the ridge thickness off the run.
- **Adding overhang without the slope factor.** The overhang is measured horizontally, so multiply it by the slope factor too.
- **Measuring to the wall centerline.** Measure the span from the outside of the walls.
- **Rounding down.** Always round up to the next stock length and cut a test rafter first.
- **Using this for hip or valley rafters.** They have different geometry. This calculator is for common rafters.

### 5.12 H2 — Rafter Calculator FAQ  (each question = H3)

**H3 — How do you calculate rafter length?**
Divide the building span by 2 to get the run, subtract half the ridge board thickness, multiply by the slope factor √(1 + (pitch ÷ 12)²), then add the overhang multiplied by the same slope factor. The result is the rafter length along its top edge.

**H3 — What is the rafter length for a 6/12 pitch?**
Every 12 in of run adds 13.42 in of rafter length on a 6/12 roof (slope factor 1.118). A 12 ft run needs about 13.42 ft of rafter before the overhang and ridge deduction.

**H3 — How long are rafters for a 12-foot-wide building?**
For a 12 ft wide gable roof at 6/12, the run is 6 ft, so each rafter is about 6 ft 8½ in before the overhang and ridge board deduction. Enter your own pitch and overhang above for an exact number.

**H3 — How do you convert roof pitch to degrees?**
Angle = arctan(rise ÷ 12). For example, 4/12 is 18.43°, 6/12 is 26.57° and 12/12 is 45°. See the roof pitch chart above for more.

**H3 — How do you calculate the pitch of a roof?**
Divide the rise by the run and multiply by 12. With a level, measure the vertical rise at the 12 in mark; that number is the pitch (for example, 6 in means 6/12).

**H3 — Do I subtract the ridge board when calculating rafters?**
Yes, for a gable roof. Subtract half the ridge board thickness from the run so the rafter ends at the face of the ridge board. A 1½ in ridge means subtracting ¾ in from the run.

**H3 — How many rafters do I need?**
Rafters per side = (building length ÷ spacing, rounded down) + 1. Double it for a gable roof. A 30 ft long building with rafters 16 in on center needs 23 per side, or 46 in total. Add extras for doubled rafters at gable ends and openings.

**H3 — How far can a 2x8 rafter span?**
There is no single answer. It depends on species, grade, spacing, roof load and local code. Check the rafter span tables in your building code or the American Wood Council's span calculator, or ask a licensed professional.

### 6.3 Formulas (exact)

```
isShed       = roofType == 'shed'
run          = isShed ? span : span / 2
slope        = pitch/12   |  tan(angle)  |  totalRise / run          // rise per 1 unit run
k            = sqrt(1 + slope²)                                      // slope factor
effRun       = run − (isShed ? 0 : ridgeThickness / 2)
mainLen      = effRun × k
overhangLen  = overhang × k
totalLen     = mainLen + overhangLen            // measured along TOP edge
totalRise    = run × slope
longPoint    = totalLen + rafterDepth × slope   // tail long-point of a plumb-cut tail
buyLen       = first of [96,120,144,168,192,216,240] in ≥ longPoint
angle        = atan(slope) in degrees
plumbCut     = angle ; levelCut = 90 − angle    // measured from a square cut
heelDepth    = plateWidth × slope ; heelRatio = heelDepth / rafterDepth
count/side   = floor(buildingLength / spacing) + 1 ; total = gable ? 2×side : side
```

### 6.9 Reference implementation (pure function — framework-independent)
> Isko apne stack (React/Next/Astro/vanilla) me wrap karo; logic mat badlo. File name: `rafterCalc.js`.

```js
// rafterCalc.js — pure function, no DOM. All lengths in INCHES.
const DEG = Math.PI / 180;
const STOCK_LENGTHS_IN = [96, 120, 144, 168, 192, 216, 240]; // 8–20 ft

export function calcRafter(i) {
  const errors = [];
  const warnings = [];
  const isShed = i.roofType === 'shed';
  const span = Number(i.span);
  const overhang = Number(i.overhang ?? 0);
  const ridgeT = isShed ? 0 : Number(i.ridgeThickness ?? 1.5);
  const depth = Number(i.rafterDepth ?? 7.25);     // actual depth: 2x6=5.5, 2x8=7.25, 2x10=9.25, 2x12=11.25
  const plate = Number(i.plateWidth ?? 3.5);       // 2x4 wall=3.5, 2x6 wall=5.5

  if (!(span > 0)) errors.push('Span must be greater than 0.');
  const run = isShed ? span : span / 2;

  let slope; // rise per 1 unit of run
  if (i.pitchMode === 'angle') {
    if (!(i.angleDeg > 0 && i.angleDeg < 80)) errors.push('Angle must be between 0° and 80°.');
    slope = Math.tan(Number(i.angleDeg) * DEG);
  } else if (i.pitchMode === 'riseRun') {
    if (!(i.totalRise > 0)) errors.push('Total rise must be greater than 0.');
    slope = Number(i.totalRise) / run;
  } else {
    if (!(i.pitch > 0 && i.pitch <= 24)) errors.push('Pitch must be between 0 and 24 (rise per 12 in of run).');
    slope = Number(i.pitch) / 12;
  }
  if (overhang < 0) errors.push('Overhang cannot be negative.');
  if (overhang > run) errors.push('Overhang is longer than the run — please check your values.');
  if (ridgeT < 0) errors.push('Ridge thickness cannot be negative.');
  if (!isShed && run - ridgeT / 2 <= 0) errors.push('Ridge thickness is too large for this span.');
  if (errors.length) return { ok: false, errors, warnings };

  const k = Math.sqrt(1 + slope * slope);          // slope factor
  const angle = Math.atan(slope) / DEG;
  const effRun = run - ridgeT / 2;
  const mainLen = effRun * k;
  const overhangLen = overhang * k;
  const totalLen = mainLen + overhangLen;          // measured along top edge
  const totalRise = run * slope;
  const longPoint = totalLen + depth * slope;      // tail long-point (plumb-cut tail)
  const buyLen = STOCK_LENGTHS_IN.find(l => l >= longPoint) ?? null;

  const heelDepth = plate * slope;                 // birdsmouth plumb (heel) cut depth
  const heelRatio = heelDepth / depth;
  if (buyLen === null) warnings.push('Longer than standard 20 ft lumber — consider engineered lumber, a purlin/mid-support design, or ask a pro.');
  if (heelRatio >= 1) warnings.push('Birdsmouth is as deep as the rafter — use a bigger rafter or a shorter seat.');
  else if (heelRatio > 1 / 3) warnings.push('Birdsmouth removes more than 1/3 of the rafter depth — use a deeper rafter or a shorter seat.');
  else if (heelRatio > 1 / 4) warnings.push('Birdsmouth is deeper than 1/4 of the rafter depth — check your local code.');
  if (slope * 12 > 12) warnings.push('Steep roof (over 12/12) — use fall protection and consult a pro.');

  let rafterCount = null;
  if (i.buildingLength > 0 && i.spacing > 0) {
    const perSide = Math.floor(i.buildingLength / i.spacing) + 1;
    rafterCount = { perSide, total: isShed ? perSide : perSide * 2 };
  }

  return {
    ok: true, errors, warnings,
    pitchPer12: slope * 12, slopePercent: slope * 100, angleDeg: angle, slopeFactor: k,
    run, effRun, totalRise,
    mainLen, overhangLen, totalLen, longPoint, buyLen,
    plumbCutAngle: angle,            // from a square cut
    levelCutAngle: 90 - angle,       // from a square cut
    seatCut: plate, heelDepth, heelRatio,
    rafterCount,
  };
}

// 173.5748 -> "14' 5 9/16\""
export function formatFtIn(inches, denom = 16) {
  const total = Math.round(inches * denom) / denom;
  let ft = Math.floor(total / 12);
  let rem = total - ft * 12;
  let whole = Math.floor(rem);
  let num = Math.round((rem - whole) * denom);
  if (num === denom) { whole += 1; num = 0; }
  if (whole === 12) { ft += 1; whole = 0; }
  const g = (a, b) => (b ? g(b, a % b) : a);
  let frac = '';
  if (num) { const d = g(num, denom); frac = ` ${num / d}/${denom / d}`; }
  return `${ft}' ${whole}${frac}"`;
}
```

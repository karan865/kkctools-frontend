## DA 1 ke liye zaroori baatein

- **Order kaise bana:** har tool ke KD ≤ 15 wale keywords ka total volume x unka CPC weight (✅ keywords). Ye sirf starting proxy hai; live SERP dekhne ke baad order badal sakta hai.
- **KD 0–15 se start karo**, lekin low KD ka matlab ranking guarantee nahi. Build se pehle US Google SERP dekho: calculators rank kar rahe hain ya articles, aur chhote/new sites top 10 me hain ya nahi.
- **Ek tool = ek page = ek primary keyword.** Supporting keywords usi page ke H2/FAQ/examples me. Alag thin pages mat banao (cannibalization).
- **AdSense approval:** sirf calculator wale pages 'low value content' me ja sakte hain. Har tool page pe 400–800 words (formula, example, FAQ) + About, Contact, Privacy Policy, Terms pages.
- **CPC** advertiser ka bid hai; AdSense me aapko isse kam milta hai. Tools compare karne ke liye use karo, earning estimate ke liye nahi.
- **Cluster me raho:** category-wise pages banao aur ek dusre ko internal link do (neeche Site structure).
- **Safety-sensitive tools** (wire gauge, pool chemicals, rebar, deck structural, stairs): sahi formulas + disclaimer. Deck load/span/permit ka output mat do.

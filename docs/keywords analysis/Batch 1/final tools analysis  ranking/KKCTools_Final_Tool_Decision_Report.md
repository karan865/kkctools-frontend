## 8. Banane se pehle check karo

- **Har tool ke top 3–5 competitor pages khud kholo:** inputs/outputs, units, mobile experience, content depth, ads. Report bhi yahi bolti hai ki screenshots sirf metrics dikhate hain, quality nahi.
- **Live SERP dobara dekho:** AI Overview, video aur image pack clicks kam kar sakte hain; report me unka asar quantify nahi hua.
- **SERP missing hain:** `reinforcement steel calculator` / `rebar calculator`, `dirt calculator` (12,100), `cost to remodel bathroom calculator` (2,900), `how much does a fence cost` (2,400), `interior painting cost` (2,900). Inke SERP screenshots add karo.
- **Formulas aur assumptions verify karo:** density (asphalt, sand, stone), bag yield (concrete), bundle coverage (shingles), brick/block sizes, rebar unit weight. Estimates ko 'estimate' likho, engineering/structural advice mat do.
- **Pricing tools (Roof, Bathroom, Fence, Slab, Paint, Deck):** reliable regional price source aur editable assumptions ke bina launch mat karo.
- **Data limits:** metrics SEMrush screenshots se transcribe hue hain; kuch URLs truncated hain; trend values readable nahi the; sirf top-10 rows li gayi hain.

### B4.1 Mode 1: Single Room
- **Units (Single Selector):** Feet & Inches (two fields per dimension), Decimal Feet, Inches, Yards, Meters, Centimeters.
- Inputs: Length and Width.
- Perimeter: Displayed as `2 × (Length + Width)`.

### B4.2 Mode 2: Multiple Rooms
- Dynamic rows: Room Name + Length + Width + **[Add / Subtract] Toggle**.
- Subtract mode handles closets, kitchen islands, cutouts, stairwells, and fireplaces.
- Per-row subtotal and grand total square footage.
- Negative Total Guard: Clamps total to 0 and displays warning message if subtractions exceed additions.
- Perimeter: Displays sum of rectangle perimeters labelled as `"approx. — does not account for doorways or shared walls"`.
- LocalStorage persistence in `try/catch`.

### B4.3 Mode 3: Shapes (v1)
- **Rectangle:** `Length × Width`
- **L-Shape (Two Rectangles A + B):** `(Length A × Width A) + (Length B × Width B)`
- **Triangle:** `(Base × Height) / 2`
- **Circle:** `π × Radius²`
- **Semi-Circle:** `(π × Radius²) / 2`
- **Trapezoid:** `((Base 1 + Base 2) / 2) × Height`
- *(Border / Donut shape removed from v1; reserved as future enhancement).*
- **Perimeter display rules:** Computable only for Circle (circumference $2\pi r$) and Semi-circle ($\pi r + 2r$). HIDE perimeter for Triangle, Trapezoid, and L-shape.

### B4.4 Global Controls & Action Buttons
- Waste presets: `0%`, `5%`, `10%`, `15%`, plus custom value field.
- Cost: Price per square foot ($/sq ft) only in v1 (drop $/m²).
- Exact button labels: `"Calculate Square Feet"`, `"Reset"`, `"Copy Summary"`, `"Print"`. Live calculation on typing; on mobile, clicking "Calculate Square Feet" scrolls results into view.
- Quick Area Converter Widget: Placed below the calculator for instant conversions between sq ft, sq in, sq yd, m², and acres.

## B5. Mathematical Engine Specification

All calculations keep full precision internally and round to 2 decimals for display.

### 5.1 Unit Conversion to Decimal Feet
- Feet: $val$
- Inches: $val / 12$
- Feet & Inches: $feet + inches / 12$
- Yards: $val \times 3$
- Meters: $val \times 3.280839895$ (where $1\text{ m} = 3.280839895\text{ ft}$)
- Centimeters: $val / 30.48$

### 5.2 Geometric Formulas
- **Rectangle Area:** $\text{Length} \times \text{Width}$; Perimeter: $2 \times (\text{Length} + \text{Width})$
- **L-Shape Area:** $(L_1 \times W_1) + (L_2 \times W_2)$; Perimeter: Hidden (null)
- **Triangle Area:** $(\text{Base} \times \text{Height}) / 2$; Perimeter: Hidden (null)
- **Circle Area:** $\pi \times r^2$; Circumference (Perimeter): $2 \times \pi \times r$
- **Semi-Circle Area:** $(\pi \times r^2) / 2$; Perimeter: $\pi \times r + 2r$
- **Trapezoid Area:** $\frac{\text{Base}_1 + \text{Base}_2}{2} \times \text{Height}$; Perimeter: Hidden (null)

### 5.3 Multi-Room Subtraction & Waste
$$\text{Raw Total Sq Ft} = \sum \text{Added Rooms} - \sum \text{Subtracted Cutouts}$$
$$\text{Total Sq Ft} = \max(0, \text{Raw Total Sq Ft})$$
$$\text{Gross Sq Ft (with waste)} = \text{Total Sq Ft} \times \left(1 + \frac{\text{Waste } \%}{100}\right)$$
$$\text{Cost} = \text{Total Sq Ft} \times \text{Price per Sq Ft}$$

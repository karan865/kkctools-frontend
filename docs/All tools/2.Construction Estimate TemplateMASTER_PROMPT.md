## 2. Product specification

### 2.1 What the tool does

A **free online construction estimate builder** that runs 100% in the browser. Users enter project details and line items (materials, labor, equipment), and the tool calculates totals with tax and markup. Users can print to PDF and download as CSV — all without creating an account or uploading anything.

### 2.2 Target audience

- **Primary:** Independent contractors, small construction companies, handymen (US/UK/CA/AU)
- **Secondary:** Homeowners getting DIY project estimates, students learning construction management
- **Tertiary:** Anyone searching for estimate templates (coming from "excel template" keywords)

### 2.3 Core features (must-have)

| ID | Feature | Description |
|---|---|---|
| F1 | Project info | Project name, client name, project address, date, estimate number (auto-generated) |
| F2 | Company info | Your company name, address, phone, email, license # (all optional, saved to localStorage) |
| F3 | Line items | Add/remove rows: description, category (dropdown), quantity, unit (dropdown), unit price, line total (auto-calc) |
| F4 | Categories | Materials, Labor, Equipment, Subcontractor, Permits & Fees, Overhead, Other |
| F5 | Units | each, sq ft, linear ft, cubic yd, hour, day, week, lump sum, ton, gallon, bag, bundle, roll, box, pallet |
| F6 | Auto-calculate | Line total = qty × unit price. Subtotal = sum of line totals. Tax = subtotal × tax%. Grand total = subtotal + tax + markup |
| F7 | Tax & markup | Tax rate % input (default 0), Markup/Profit % input (default 0). Both optional. |
| F8 | Category subtotals | Show subtotal per category (e.g., "Materials: $12,500 · Labor: $8,000") |
| F9 | Print to PDF | `window.print()` with dedicated `@media print` CSS. Clean, professional layout. No "print" button visible in print. |
| F10 | Download CSV | Download all line items + totals as .csv file via Blob API |
| F11 | Download TXT | Download formatted estimate as plain text via Blob API |
| F12 | Save estimate | Save current estimate to localStorage. Show "Saved!" toast. |
| F13 | Load estimate | Load previously saved estimate from localStorage. Dropdown of saved estimates (by project name + date). |
| F14 | New estimate | Clear all fields, start fresh. Confirm dialog before clearing. |
| F15 | Starter template | Pre-fill with a sample residential construction estimate on page load (static HTML for SEO crawlers). |
| F16 | Currency | USD default. Dropdown: USD ($), GBP (£), CAD (C$), AUD (A$), EUR (€). Saved to localStorage. |
| F17 | Notes section | Free-text area for terms, conditions, payment schedule, warranty info |
| F18 | Estimate validity | "This estimate is valid for __ days" (default 30) |

### 2.4 Non-features (do NOT build)

- No user accounts, no login
- No server-side anything — everything runs in the browser
- No AI generation of estimates
- No real-time pricing data / material cost API
- No sharing via URL (localStorage only)
- No image upload (keeps it simple and fast)

### 2.5 Technical constraints

All rules from `AGENTS.md` apply. Additionally:

1. **Zero network calls.** The estimate builder runs entirely client-side. No `fetch`, `XMLHttpRequest`, `sendBeacon`, `WebSocket`. Verified by `npm run check:no-network` (update the script to also scan `src/components/tool/construction-estimate/`).
2. **No new dependencies.** Use only the allowed list from the existing project. PDF = `window.print()`. CSV/TXT = `Blob` + `URL.createObjectURL`. Currency formatting = `Intl.NumberFormat`.
3. **localStorage for persistence.** Use the existing `safeStorage` helper from `src/lib/storage.ts`.
4. **Static HTML for SEO.** The starter template must render in the initial HTML (server component passes data, client component hydrates). Google must see a working estimate example in the static HTML.

## Appendix A: Style guide for the tool

The construction estimate tool should feel **professional and trustworthy** — this is a business tool, not a fun generator.

### Color notes (use existing design tokens)
- Use `--color-surface` for form backgrounds
- Use `--color-primary` for action buttons (Print, Download)
- Use `--color-success` for positive totals
- Use `--color-muted` for secondary text (labels, placeholders)
- Category badges: use subtle colored pills (similar to Chip component)

### Typography
- Table headers: bold, smaller font size
- Currency amounts: monospace-style or tabular figures (`font-variant-numeric: tabular-nums`)
- Grand total: larger, bold, primary color
- Print layout: use serif font for professional feel (or keep existing font)

### Micro-interactions
- Line total updates instantly when quantity/price changes
- Subtotals and grand total animate briefly (CSS transition) on change
- "Saved!" toast appears for 3 seconds
- Delete row: brief fade-out animation
- Add row: row slides in with brief animation
